# Web Development Assignments – Complete Starter Code

This folder contains 13 separate mini-projects. Open each folder independently.

## Run instructions
- Projects 1–7: open `index.html` in a browser. Projects using APIs need an internet connection.
- Projects 8–12: open a terminal in that project folder, run `npm install`, then `npm start`.
- Project 13: run `npm install` and `npm run dev` inside `13-react-portfolio`.

## Express projects
Use Node.js 18+ (20+ recommended). MongoDB projects need a running MongoDB server and a `.env` file based on `.env.example`.

## Important
- Project 11 uses a local JSON file as a simple demo data store; Project 12 uses MongoDB.
- Project 12 checkout is a demonstration order flow, not a real payment gateway. Never collect or store card details yourself. For real payments, integrate a provider such as Razorpay or Stripe on the server and verify payment signatures/webhooks.
- Change demo credentials and secrets before deploying. Add validation, authentication, authorization, rate limiting, and error handling before production use.
